# RHACS UX Prototypes

Static UX prototypes for **Red Hat Advanced Cluster Security (RHACS)**. This tree is **vendored in the OpenShift UX design monorepo**; see **`VENDOR.md`** for how the prototype hub embeds it and how to refresh builds.

In the hub, **Baseline** vs **Saved filters** are two cards; both use this build — **`?surface=baseline`** vs **`?surface=saved-filters`** on `/embed/rhacs-ux-prototypes`.

- **Saved Filters v1** — `saved-filters/`
- **Catalog** (searchable gallery) — `catalog.html`
- **Root** — `index.html` redirects into Saved Filters
